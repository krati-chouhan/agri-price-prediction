Developer REST API Reference

The application exposes programmatic JSON endpoints for mobile apps and conversational integrations:

Method Endpoint Description Sample Response
POST /api/predict Submit JSON with crop, Indian State, rainfall, temperature, humidity to get 12-month projections. {"success": true, "kpis": {...}, "forecast": [...]}
POST /api/chat Chatbot conversational endpoint accepting natural language questions about prices, storage, and MSP. {"reply": "...", "suggestions": [...]}
GET /api/crops Returns supported crops (Potato, Onion, Pulses, etc.). {"crops": ["Potato", "Onion", "Pulses", ...]}
GET /api/locations Returns Indian States, default climate parameters, and APMC Mandi hubs. {"locations": ["Maharashtra", "UP", ...]}
GET /api/metrics Model performance metrics (R², RMSE, feature importances). {"random_forest": {"r2": 0.9874}}
